# T01 桌面端骨架 + 凭证列表

> 执行：Antigravity（Gemini）。开始前先读 `docs/README.md`、`docs/CONTRACT.md`，再读本卡。

## 背景

财务工作台是 Tauri + React 的本地桌面应用。后端本机服务已经写好（`services/core`，监听 127.0.0.1:8765，带演示数据）。
接口契约在 `apps/desktop/src/shared/api.ts`，界面原型在 `docs/prototype/`（11 个页面 + `app.css`）。
这张卡要做出能跑起来的桌面端外壳，并把“记账”页的凭证列表接上真实接口，这是技术验证链路里“界面显示”那一段。

## 任务

1. **建工程**：在 `apps/desktop/` 用 Tauri 2 + React 18 + TypeScript + Vite 建工程（`npm create tauri-app` 的 react-ts 模板即可）。
   - 保留已有的 `src/shared/api.ts`，不要改它。
   - 开发端口 1420（后端 CORS 已放行 `http://localhost:1420`、`tauri://localhost`、`http://tauri.localhost`）。
   - 不引入 UI 组件库（不要 antd、MUI、shadcn 之类），样式用原型的 CSS。可以用 `react-router-dom`。
2. **Tauri 命令 `get_backend_config`**（Rust，`src-tauri/src/lib.rs`）：返回 `{ baseUrl, token }`。
   - token 读取数据目录里的 `api-token` 文件：Windows `%APPDATA%\FinanceWorkbench\api-token`，其他系统 `~/.finance-workbench/api-token`；环境变量 `FW_DATA_DIR` 优先。
   - baseUrl 默认 `http://127.0.0.1:8765`，环境变量 `FW_PORT` 可改端口。
   - 文件不存在时返回明确错误，前端显示“本机服务未启动”的提示页，带“重试”按钮。
   - 第一期不由 Tauri 拉起 Python 服务（手动启动），不要做 sidecar。
3. **样式**：把 `docs/prototype/app.css` 复制为 `apps/desktop/src/styles/app.css`，保留变量名和类名；字体（Noto Sans SC / Noto Serif SC）用 `@fontsource` 包本地引入，不走 Google Fonts。
4. **外壳布局**（对照 `docs/prototype/Main.dc.html` 和 `Ledger.dc.html`）：
   - 左侧导航：收起按钮 + 衬线“财务工作台”、搜索框“搜索或跳转 Ctrl K”、导航项（首页、记账、发票、银行对账、报销、报表、AI 对话、文件工作区、知识库、工具箱），底部深色模式切换、设置、当前用户。
   - 中间主区：顶栏标题 + 页面内容。
   - 右侧栏：默认关闭，打开时显示详情。
   - 左/中、中/右之间是原型里的 `.split` 分割线，可拖动调宽，有最小/最大宽度，宽度存 localStorage；双击分割线恢复默认宽度。
   - Ctrl K 打开命令面板（原型 `.palette`），能按名称跳转页面。
   - 深色模式：切换 `.app.dark`，存 localStorage。
   - 除“记账”外，其他页面先放一个空状态占位（标题 + 一句“即将上线”）。
5. **当前用户**：设置里（或左下角用户菜单）能选/输入当前操作人姓名，存 localStorage，作为 `createClient` 的 `user`。默认“李会计”。
6. **记账页 - 凭证列表**（对照 `Ledger.dc.html` 的列表部分）：
   - 用 `api.vouchers()` 拉数据，表格列：日期、凭证号、摘要（第一行摘要）、借方科目、金额（`total`，右对齐等宽数字）、状态、制单人。
   - 筛选：期间下拉（来自 `api.periods()`）、状态（全部/草稿/已审核/已记账）、关键字搜索（输入停顿 300ms 再查）。
   - 状态用原型的 `.tag` 样式；`source === "ai"` 的行额外显示“AI 草稿”标记。
   - 点一行，右侧栏打开凭证详情：分录表（摘要、科目编码+名称、借方、贷方）、合计、制单/审核/记账人。
   - 详情里按状态显示按钮：草稿 →“审核”，已审核 →“反审核”“记账”。调用对应接口，成功后刷新列表和详情；失败时把 `ApiError.message` 用原型样式的提示条显示出来（不要用 `alert`）。
   - 加载中、空列表、接口出错三种状态都要有样子。

## 验收标准

1. `cd apps/desktop && npm install && npm run tauri dev` 能在 Windows 上打开窗口。
2. 后端没启动时，显示“本机服务未启动”提示；按 README 启动后端（`FW_DEMO=1`）后点“重试”能进入。
3. 记账页显示 5 张演示凭证，其中 2 张草稿；按“差旅”搜索只剩 1 张；按状态“草稿”筛选剩 2 张。
4. 当前用户为“李会计”时审核自己做的凭证，界面显示后端返回的“审核人不能是制单人”；切换为“王主管”后审核成功，状态变“已审核”，再点“记账”变“已记账”。
5. 三栏分割线可拖动，重启应用后宽度保持；双击恢复默认。
6. Ctrl K 能打开面板并跳转到“记账”。深色模式切换正常，重启后保持。
7. 所有图标按钮有悬浮提示。
8. `npm run build` 无 TypeScript 错误（`strict: true`）。
9. 代码里没有把金额 `Number()`/`parseFloat()` 后做运算的地方（显示用千分位格式化可以，写成一个 `formatMoney(s: string)` 工具函数，只做字符串处理）。
10. 写了 `docs/reports/T01-report.md`。
