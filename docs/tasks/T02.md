# T02 本机打通 Hermes + DeepSeek + 财务工具

> 执行：用户在自己 Windows 电脑上操作，可以让 Antigravity（Gemini）协助排错。和 T01 互不依赖，可以同时做。
> 这张卡不写业务代码，目的是确认 Hermes 能在本机通过 MCP 调用我们的财务工具。

## 背景

`services/core/src/finance_core/mcp_server.py` 是给 Hermes 的财务工具（查凭证、查余额、科目余额表、建草稿凭证），在云端测试环境里已用 MCP 客户端端到端测过。
`integrations/hermes/` 里是 Hermes 的专用配置。需要在真实 Windows + Hermes + DeepSeek 上验证一遍。

## 步骤

1. 安装后端：
   ```
   cd services\core
   python -m venv .venv
   .venv\Scripts\activate
   pip install -e ".[dev]"
   pytest
   ```
2. 安装 Hermes Agent（按官方 README 的 Windows 方式），然后建专用 profile：`hermes profile create finance`。
3. 把 `integrations/hermes/config.yaml` 的内容合并进 finance profile 的 `config.yaml`；
   把 `mcp_servers.finance.command` 改成上一步虚拟环境里 python 的完整路径，例如
   `C:\...\services\core\.venv\Scripts\python.exe`。
4. 复制 `integrations/hermes/.env.example` 为 finance profile 目录下的 `.env`，填 DeepSeek Key、`API_SERVER_KEY`（自己生成一串随机字符）、`FW_DATA_DIR`。
5. 先用命令行验证：`hermes -p finance chat`，问“11 月银行存款余额是多少？”和“查一下差旅费凭证”。
   - 配置里 `FW_DEMO: "1"` 会让工具自动写入演示数据（只在空库时写一次）。
6. 再验证 API Server：`hermes -p finance gateway`，另开一个 PowerShell：
   ```
   curl.exe http://127.0.0.1:8642/v1/chat/completions -H "Authorization: Bearer 你的API_SERVER_KEY" -H "Content-Type: application/json" -d "{\"model\":\"hermes-agent\",\"messages\":[{\"role\":\"user\",\"content\":\"11月管理费用一共多少\"}]}"
   ```
7. 最后通过工作台本地服务转发（PowerShell）：
   ```
   $env:FW_DEMO="1"; $env:HERMES_API_KEY="你的API_SERVER_KEY"; finance-core
   ```
   另开一个窗口（令牌在 `%APPDATA%\FinanceWorkbench\api-token`）：
   ```
   curl.exe -N http://127.0.0.1:8765/api/chat -H "Authorization: Bearer 令牌" -H "X-FW-User: %E6%9D%8E%E4%BC%9A%E8%AE%A1" -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"查一下差旅费凭证\"}]}"
   ```
   应该看到逐段返回的 SSE，其中有 `event: hermes.tool.progress`。

## 验收标准

1. `pytest` 17 项通过。
2. 第 5 步：回答里银行存款期末 498720.00（只算已记账），并说明是否含未记账；差旅费能找到“张三出差北京报销 3560.00”。
3. 第 5 步再让它“做一张 11 月 20 日支付办公用品 500 元的凭证”：生成的是**草稿**，回复里有凭证号；再让它“把这张凭证审核并记账”，它应该说明做不到（后端返回“审核必须由人操作”）。
4. 第 6 步 curl 返回正常回答；不带 Authorization 时被拒绝。
5. 确认 API Server 模式下 Hermes 没有终端、文件工具（问它“列出你能用的工具”）。
6. 写 `docs/reports/T02-report.md`：每一步的结果、截图或输出片段、遇到的报错和怎么解决的、Hermes 版本号。
