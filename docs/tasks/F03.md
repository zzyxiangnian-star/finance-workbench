# F03 账簿：明细账、总账、期初余额

> 执行：Cursor。分支：`f03-books`（从合并了 F01 的 main 拉）。开始前读 `docs/cursor/PLAN.md`、`docs/UI.md`、`.cursor/rules/`。
> F02 可能和这张卡同时在做。两边都会改 `api.py`、`api.ts`、`CONTRACT.md`。交付前先 `git fetch && git rebase origin/main`，有冲突就两边都保留。

## 背景

现在能录凭证、审核、记账，但看不了账：记账页的“账簿”标签还是“即将上线”。期初余额只有后端的 `Ledger.set_opening_balance`，界面录不了，也没有试算平衡。
这张卡做三件事：
- 期初余额录入，带试算平衡。
- 明细账（三栏式：借方、贷方、余额）。
- 总账（本月合计、本年累计）。

格式按国内会计的习惯，和用友、金蝶的账簿一样读。

## 名词和规则

- **建账期间** `start_period`：账从哪个月开始记，存在 `meta` 表，键是 `start_period`。
  - `seed_demo` 设为 `2026-11`。
  - `seed_accounts` 第一次建库时设为当月。
  - 老库没有这个键时，取 `opening_balances` 和 `vouchers` 里最早的期间，都没有就取当月，读到后写回 `meta`。
- **期初余额**：建账期间月初的余额，只录末级科目。按科目余额方向记，可以是负数（表示反方向余额）。
  - 上级科目的期初是下级的汇总，只读。
  - 损益类（`category = 'pl'`）的期初必须为 0，否则报 `pl_opening`：“损益类科目没有期初余额”。
- **本年累计发生额**：建账期间不是 1 月时，要录“年初到建账前”的累计借方、累计贷方，后面利润表的“本年累计”要用。损益类也要录。
  - 年初余额由系统算：年初余额 = 期初余额 − 方向符号 ×（累计借方 − 累计贷方）。
  - 存在新表 `opening_ytd(account_code, period, debit_cents, credit_cents, PRIMARY KEY(account_code, period))`。
  - 新表加在 `db.py` 的 `SCHEMA` 末尾，用 `CREATE TABLE IF NOT EXISTS`，不升 `SCHEMA_VERSION`。每次连接都会执行 `SCHEMA`，老库自动建表。
- **试算平衡**：所有末级科目的期初余额，按方向折算后，借方合计 = 贷方合计。算法和 `trial_balance` 里的 `ob_dr`、`ob_cr` 一致。
- **期初锁定**：只要有一张已记账凭证，或者有一个期间已结账，期初余额和本年累计都不能再改，报 `opening_locked`：“已有记账凭证，期初余额不能再改”。
- **建账期间锁定**：已有任何凭证（包括草稿）时不能改建账期间，报 `start_period_locked`。改建账期间时，把 `opening_balances`、`opening_ytd` 里的行一起移到新期间。
- **记账前检查**：`Ledger.post` 增加一条检查：期初不平衡时不能记账，报 `opening_unbalanced`：“期初余额不平衡（借方 …，贷方 …），请先调整期初”。如果已有测试因此失败，改测试数据让期初平衡，不要去掉这条规则。
- **建账前的凭证**：凭证日期早于建账期间时，新建和修改都拒绝，报 `before_start`：“凭证日期早于建账期间 2026-11”。
- **余额方向**：账簿里每个余额都带方向：
  - 余额与科目方向一致，方向就是科目方向。
  - 余额相反，方向就是另一边。
  - 余额为零，方向是“平”。
  - 金额一律显示绝对值。

## 任务

### 后端（services/core）

新逻辑放到新文件 `finance_core/books.py`，函数接收 `Ledger`（用它的 `conn`）。`ledger.py` 只加上面说的 `post` 检查、`before_start` 检查和 `start_period` 的读写。

1. **期初余额**
   - `GET /api/opening-balances` 返回：
     ```json
     {
       "start_period": "2026-11",
       "mid_year": true,
       "locked": false,
       "lock_reason": null,
       "items": [{
         "account_code": "1002", "account_name": "银行存款",
         "category": "asset", "direction": "debit",
         "parent_code": null, "level": 1, "is_leaf": false,
         "amount": "500000.00", "ytd_debit": "0.00", "ytd_credit": "0.00", "year_opening": "500000.00"
       }],
       "totals": {"dr": "500000.00", "cr": "500000.00", "diff": "0.00", "balanced": true}
     }
     ```
     - `mid_year` 表示建账期间不是 1 月。
     - `items` 包含全部启用科目，按编码排序。上级科目的数是下级的汇总，`level` 从 1 开始。
   - `PUT /api/opening-balances`：请求体 `{"start_period"?: "2026-11", "items": [{"account_code", "amount", "ytd_debit"?, "ytd_credit"?}]}`。
     - 一次保存多行，在一个事务里完成。返回和 GET 一样的结构。
     - 只接受末级科目，否则报 `not_leaf`。
     - 不平衡也允许保存（会计常常分几次录完），平衡状态看 `totals`。
     - 每行写一条操作日志。
     - AI 身份报 `ai_forbidden`（界面接口本来就拒绝 `ai:`，`Ledger` 里也要拦）。
2. **账簿期间**：`GET /api/books/periods` 返回从建账期间到“最后一张凭证的期间”和“当月”两者中较晚那个的所有期间，升序。
3. **明细账**：`GET /api/books/detail?account_code=1002&period_from=2026-11&period_to=2026-11&include_unposted=false`
   - 科目可以是上级科目：汇总所有下级的分录，每行带上实际的末级科目。
   - 返回：
     ```json
     {
       "account": {"code": "100201", "name": "银行存款-基本户", "direction": "debit"},
       "include_unposted": false,
       "opening": {"period": "2026-11", "side": "debit", "amount": "500000.00"},
       "periods": [{
         "period": "2026-11",
         "lines": [{"voucher_id": 1, "display_no": "记-0001", "status": "posted", "date": "2026-11-03",
                    "account_code": "100201", "account_name": "银行存款-基本户", "summary": "购买办公用品",
                    "debit": "0.00", "credit": "1280.00", "side": "debit", "balance": "498720.00"}],
         "month": {"debit": "0.00", "credit": "1280.00", "side": "debit", "balance": "498720.00"},
         "year":  {"debit": "0.00", "credit": "1280.00", "side": "debit", "balance": "498720.00"}
       }]
     }
     ```
     `side` 取值为 `debit`、`credit` 或 `flat`。
   - 排序：日期、凭证字、凭证号、行号。`balance` 是逐行滚动的余额。
   - 范围里没有发生额的月份也要输出，`lines` 为空，`month`、`year` 照算。
   - 本年累计 = 同一年里从 max(1 月, 建账期间) 到本月的发生额。如果建账期间在这一年，再加上 `opening_ytd`。
   - 校验：
     - `period_from` 早于建账期间时，按建账期间算，`opening.period` 会说明实际起点。
     - `period_from > period_to`，或者跨度超过 24 个月，报 `bad_range`。
     - 科目不存在报 `account_not_found`。
4. **总账**：`GET /api/books/general?...`，参数同上。返回同样的结构，但不带 `lines`。和明细账共用一个计算函数。
5. **MCP 工具**：`mcp_server.py` 加只读工具 `detail_ledger(account_code, period_from, period_to, include_unposted=false)`，直接调 `books.py`。AI 问“管理费用这个月花在哪了”时能用。
6. **测试**：
   - 期初录入、汇总、试算平衡。
   - 锁定：记账后改期初报错；有凭证时改建账期间报错。
   - `pl_opening`、`not_leaf`、`before_start`。
   - 期初不平时 `post` 报错。
   - 明细账的滚动余额和方向，包括余额变成反方向和变成“平”的情况。
   - 上级科目汇总。
   - 跨两个月和跨年的本年累计。在测试里自己建 2026-12、2027-01 的凭证，不改演示数据。
   - `include_unposted` 开和关的区别。
   - MCP 工具能列出来，也能调用。
7. `api.ts` 加类型和函数：`openingBalances`、`saveOpeningBalances`、`bookPeriods`、`detailLedger`、`generalLedger`。`docs/CONTRACT.md` 第 2 节表格补上这些接口，第 3 节补上锁定规则。

### 前端（apps/desktop）

8. **入口**：记账页的“账簿”标签换成真页面。标签状态写进 URL：
   - `/ledger?tab=books&book=detail&account=100201&from=2026-11&to=2026-11&unposted=1`
   - `book` 取 `detail`（明细账）、`general`（总账）或 `opening`（期初余额）。
   - 用 URL 是为了以后报表和 AI 回答能直接链接到某个科目的明细账。
   - 原来的“凭证”标签也用 `tab=vouchers`，没有 `tab` 时默认凭证。
   - 账簿标签下方用小号分段按钮切换“明细账 | 总账 | 期初余额”（复用 `.tabs` 样式，或在 `desktop.css` 加一个小号变体）。
   - 顶栏原来的单期间下拉在账簿标签下隐藏，期间范围放在账簿工具条里。
9. **明细账、总账共用的工具条**：
   - 科目选择：复用 `AccountPicker`，加一个 `allowParent` 属性，让上级科目也能选。
   - 旁边放两个图标按钮“上一个科目”“下一个科目”（带 `Tip`），只在有发生额或有期初的科目之间跳。可以用 `/api/reports/trial-balance` 的结果得到这个列表。
   - 期间“从”“到”两个下拉，选项来自 `/api/books/periods`。
   - “含未记账”开关，打开后表头旁显示一个 `warn` 标签“含未记账”。
   - 没选科目时显示空状态，提示“选一个科目查看明细账”。
10. **明细账表格**：
    - 列：日期 | 凭证号 | 摘要 | 借方 | 贷方 | 方向 | 余额。查上级科目时，在摘要和借方之间加一列“科目”。
    - 第一行是“期初余额”：只填方向和余额，字体灰。
    - 每个月的分录之后是“本月合计”行，再是“本年累计”行，两行加粗，上面有细线。
    - 金额右对齐，用 `formatMoney`，为零的格子留空。方向显示“借”“贷”“平”。
    - 未记账的分录行，凭证号后加一个小标签“未记账”。
    - 凭证号可以点：在右侧栏打开凭证详情（复用 `VoucherDetail`），右侧栏关着时自动打开。
    - 表头吸顶，长表格只滚动表体。
11. **总账表格**：
    - 列：期间 | 摘要 | 借方 | 贷方 | 方向 | 余额。
    - 第一行“期初余额”，然后每月两行“本月合计”“本年累计”。
    - 点“本月合计”行，切到这个科目这个月的明细账。
12. **期初余额页**：
    - 顶部：建账期间下拉（有凭证时禁用，悬浮提示写原因）、搜索框（编码、名称、拼音首字母，复用 `py` 字段过滤）、“保存”按钮。
    - 表格列：编码 | 科目名称 | 方向 | 期初余额。`mid_year` 时在“方向”和“期初余额”之间加“年初余额（只读）| 本年累计借方 | 本年累计贷方”。
    - 科目按层级缩进；上级科目行加粗、只读，数字随下级实时汇总（前端用 `lib/format.ts` 的 BigInt 函数算，不要转 number）。
    - 末级科目的格子用 `MoneyInput`。加一个 `allowNegative` 属性，允许一个前导负号。
    - 损益类科目的期初格禁用，悬浮提示“损益类科目没有期初余额”；它们的本年累计可以填。
    - Enter 或下键跳到下一行同一列，上键回上一行，跳过只读行。
    - 底部固定一条试算平衡栏：借方合计、贷方合计、差额，带 `ok`“试算平衡”或 `bad`“不平衡，差额 …”标签。表格滚动时这条栏不动。
    - 锁定时整页只读，顶部用 `<Alert>` 显示 `lock_reason`。
    - 有未保存的修改时，切标签或离开页面要先确认（复用 F01 的离开保护）。
    - 保存成功用页面内的轻提示，不要用 `alert()`。
13. **顺手的穿透**：
    - 凭证详情（`VoucherDetail`）里每行的科目名可以点，跳到这个科目在该凭证期间的明细账。
    - 录入页右侧栏的科目余额卡片下面加一个链接“查看明细账”。
14. 深色模式正常；所有图标按钮带悬浮提示；空状态、加载中、报错三种状态都有。
